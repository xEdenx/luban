# 统一需求交付入口

用户输入：

```text
$ARGUMENTS
```

开发者无需选择 L0～L3。先读取业务仓库内 `.specify/extensions/team-sdlc/references/flow.md`，完成其中的强制风险评估并根据评估结果走相应路径。随后自动衔接原生能力，仅在必要确认、关键疑问或阻塞处暂停。该文件不存在时报告安装不完整，不自行猜测流程。恢复现有变更时复核已有风险与确认记录，不创建第二份需求。
