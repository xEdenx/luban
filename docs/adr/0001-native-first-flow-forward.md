# ADR-0001：Spec Kit 原生优先与 Flow-forward

日期：2026-10-10。状态：已接受，承接用户明确决策。

## 背景

团队曾发生历史 Spec 与后续 Chat 修改逐渐脱节，希望有成熟项目支持，又能减少重复工作和过度框架约束。

## 决策

采用 GitHub Spec Kit 1.x 原生机制；Flow-forward 管理本轮增量意图与历史；L0–L3 控制流程深度；AC-to-Test 作为必要扩展；AGENTS.md、Skills 与验收执行器各司其职。未来使用官方 Bundle 分发经过验证的团队组件。

活跃变更可修订并重新确认；变更整体交付后冻结历史。当前工程知识由代码、测试、接口契约、长期设计和 ADR 持续维护。

## 后果

先核验原生能力，再配置/薄适配，最后才开发扩展。不另建 Spec 引擎、任务状态系统或中央编排器。已完成 Spec 仍需关联后续变更，避免历史碎片被当作当前真相。

精确版本、真实客户端兼容性与业务验收要分别验证。正文：[技术设计](../technical-design.md)。
