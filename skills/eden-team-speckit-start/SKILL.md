# eden-team-speckit-start

在当前业务工程读取 `.specify/extensions/team-sdlc/commands/start.md` 并执行其中指令；该文件继续引用同一安装内的共享执行约定与原生 Spec Kit 能力。本 Skill 只提供团队调用名称，不另实现一套流程。

将当前真实用户的需求、增量描述、修订或确认作为输入；若文中的 $ARGUMENTS 未被宿主替换，使用当前用户输入，不把占位符当成需求。任何等级入口都必须先评估实际风险，不能因选择低等级而绕过确认。

安装文件不可读取时报告接入不完整，不猜测流程或声称已执行。已有活跃变更按其具体版本和确认记录恢复；仅在必要确认、关键疑问或阻塞时暂停，确认后自动继续。
